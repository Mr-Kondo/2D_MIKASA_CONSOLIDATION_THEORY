# 有限ひずみ圧密の理論（解説）

対象は `finite_strain.py` の `FiniteStrainConsolidation` です。単位は長さ m、時間 day、応力 kPa、間隙比は無次元です。
地表が $`z=0`$、固定底面が $`z=\mathrm{depth}`$ で、沈下は下向きを正とします。

この文書は、本実装が解いている式と、その導出、仮定、限界を説明します。
原著（三笠 1963 など）の本文は確認しておらず、以下の導出は本実装の内容と有限ひずみ圧密の標準的な定式化に沿って著者が書き下したものです。
文献ごとの確認状況は [references.md](references.md) にあります。

## 1. 記号

| 記号 | 意味 |
| --- | --- |
| $`z`$ | 物理深さ（変形とともに動く。下向き正）。 |
| $`\zeta`$ | 物質座標。地表で0、下向き正。単位面積あたりの固体体積。 |
| $`\xi`$ | 水平方向の物理座標（二次元化で使う）。 |
| $`e`$ | 間隙比（間隙体積 ÷ 固体体積）。 |
| $`e_0`$ | 参照有効応力 $`\sigma'_{\mathrm{ref}}`$ における間隙比。 |
| $`\sigma,\ \sigma'`$ | 鉛直全応力、鉛直有効応力。 |
| $`u`$ | 過剰間隙水圧。自重と釣り合った初期状態からの増分。 |
| $`k`$ | 透水係数（速度の次元）。 |
| $`k_0`$ | 参照透水係数（$`e=e_0`$ のときの値）。 |
| $`C_c,\ C_k`$ | 圧縮指数、透水指数。 |
| $`a_v`$ | 圧縮係数。$`a_v=C_c/(\sigma'\ln 10)`$。 |
| $`\gamma_w,\ G_s`$ | 水の単位体積重量、土粒子の比重。 |
| $`t`$ | 時間。 |
| $`\Delta\zeta,\ \Delta\xi`$ | 格子幅（時間によらない）。 |
| $`n_z,\ n_x`$ | 鉛直・水平の格子数。 |

## 2. なぜ有限ひずみか

寺田（Terzaghi）の一次元圧密は、ひずみが小さく、層厚が変わらず、透水係数と圧縮係数が一定という仮定の下で成り立ちます。
軟弱粘土では間隙比が2〜4程度になり、層厚の減少量が無視できません。
圧密の進行とともに透水係数と圧縮性も変わります。

これらの効果を同時に扱うには、変形とともに動く座標と、間隙比に依存する材料則が要ります。
本実装は、物質座標と間隙比の材料則でこれを扱います。

## 3. 物質座標

単位面積あたりの固体体積を座標に使います。
間隙比 $`e`$ の要素では、固体体積 $`dV_s`$ に対する全体積が $`(1+e)\,dV_s`$ です。
深さ方向の厚み $`dz`$ は $`(1+e)\,dV_s`$ に等しいので、$`dV_s=dz/(1+e)`$ です。
地表から深さ $`z`$ までの固体体積は

$$
\zeta=\int_0^{z}\frac{dz'}{1+e(z')}
$$

です。$`\zeta`$ は固体体積を表し、地表で0、下向きに増えます。

固体は系から流出しないので、材料要素の $`\zeta`$ 幅は時間によらず一定です。
層厚の減少は、$`\zeta`$ から物理深さ $`z(\zeta)`$ への写像の変化として現れます。
これが移動表面です。本実装はこの写像を毎回計算し、格子は $`\zeta`$ 上に固定します。

## 4. 材料則

圧縮則は、有効応力と間隙比を結びます。

$$
e=e_0-C_c\log_{10}\frac{\sigma'}{\sigma'_{\mathrm{ref}}}.
$$

有効応力が $`\sigma'_{\mathrm{ref}}`$ のとき $`e=e_0`$ です。$`C_c`$ が大きいほど圧縮しやすい材料です。

両辺を微分すると $`\partial e/\partial\sigma'=-C_c/(\sigma'\ln 10)=-a_v`$ なので、$`a_v=C_c/(\sigma'\ln 10)`$ です。
本実装は逆に、$`e`$ から有効応力を $`\sigma'=\sigma'_{\mathrm{ref}}\,10^{(e_0-e)/C_c}`$ で求めます。

透水則は、間隙比と透水係数を結びます。

$$
k=k_0\,10^{-(e_0-e)/C_k}.
$$

$`e`$ が減る（圧密する）ほど $`k`$ が減ります。$`C_k`$ は透水指数です。
土は飽和とし、水の流れはDarcy則 $`v=-(k/\gamma_w)\,\partial u/\partial z`$ に従うとします。

## 5. 貯留式（支配方程式）

単位面積あたりの材料要素（固体体積 $`\Delta\zeta`$）の中の水の体積は $`e\,\Delta\zeta`$ です。
水の収支から、固体に対する水の流速を $`v`$ とすると $`\partial e/\partial t=-\partial v/\partial\zeta`$ です。

物質座標では $`\partial z/\partial\zeta=1+e`$ なので、$`\partial u/\partial z=(1/(1+e))\,\partial u/\partial\zeta`$ です。
これをDarcy則に代入すると $`v=-(k/(\gamma_w(1+e)))\,\partial u/\partial\zeta`$ となり、収支の式は

$$
\frac{\partial e}{\partial t}
=\frac{\partial}{\partial \zeta}\left[\frac{k}{\gamma_w(1+e)}\frac{\partial u}{\partial \zeta}\right]
\tag{1}
$$

になります。これが本実装の鉛直一次元の支配方程式です。

次に $`u`$ を $`e`$ と結びます。飽和土の単位体積重量は $`(\gamma_wG_s+e\gamma_w)/(1+e)=\gamma_w(G_s+e)/(1+e)`$ なので、
全応力の勾配は

$$
\frac{\partial \sigma}{\partial \zeta}=\gamma_w(G_s+e)
$$

です。有効応力は圧縮則の逆関数で $`e`$ から決まり、$`\partial\sigma'/\partial\zeta=-(1/a_v)\,\partial e/\partial\zeta`$ です。
$`u=\sigma-\sigma'`$ だから

$$
\frac{\partial u}{\partial \zeta}
=\gamma_w(G_s+e)+\frac{1}{a_v}\frac{\partial e}{\partial \zeta}
\tag{2}
$$

です。(2) を (1) に代入すると、$`e`$ だけの形になります。

$$
\frac{\partial e}{\partial t}
=\frac{\partial}{\partial \zeta}\left[
\frac{k(G_s+e)}{1+e}
+\frac{k}{\gamma_w(1+e)a_v}\frac{\partial e}{\partial \zeta}\right].
\tag{3}
$$

第1項は自重で生じる流れ、第2項は圧密で生じる流れです。

## 6. 初期条件と境界条件

初期状態は、地表応力 $`\sigma_{\mathrm{top}}`$ と自重に有効応力が釣り合うプロファイルです。

各セルで $`\sigma'_i=\sigma'_{i-1}+\gamma_w\Delta\zeta\,(G_s+(e_{i-1}+e_i)/2)`$ を、$`e`$ が $`\sigma'`$ に依存するため不動点反復で解きます（台形則）。
層厚が `depth` になる固体厚 $`\Delta\zeta\,n_z`$ は二分法で求めます。

荷重は $`t=0`$ に瞬時に加え、載荷の瞬間には排水が起きないとします。
すると初期の過剰間隙水圧は、載荷による全応力の増分に等しくなります。本実装では $`u(x,z,0)=\sigma_{\mathrm{load}}(x,z)`$ です。
鉛直一次元（`nx=1`）では $`\sigma_{\mathrm{load}}=\texttt{load\_intensity}`$ が一様に入ります。

境界条件は次のとおりです。

- 地表 $`\zeta=0`$: 排水。$`u=0`$。
- 底面 $`\zeta=n_z\Delta\zeta`$: 非排水。フラックス0。
- 側方 $`\xi=0,\ \xi=\mathrm{length}`$: 非排水。フラックス0。

定常状態ではフラックスが0になり、$`u=0`$ に達します。有効応力は自重と載荷を含む全応力に一致します。

## 7. 沈下とひずみ

圧密による層厚の減少量は、各要素の $`(1+e)\Delta\zeta`$ の減少量の和です。固体体積 $`\Delta\zeta`$ は一定なので

$$
s=\int (e_{\mathrm{initial}}-e)\,d\zeta
$$

です。本実装は底面を基準に下向きへ累積し、沈下 `disp_z` とします。
鉛直ひずみは $`\varepsilon_z=(e_{\mathrm{initial}}-e)/(1+e_{\mathrm{initial}})`$ です。
水平変位は、二次元化の仮定（$`\varepsilon_x=0`$）の下で0とします。

## 8. 数値解法

- **空間**: セル中心の有限体積。セルは $`\zeta`$ で等分し、面でフラックスを評価します。面の間隙比は隣接セルの平均です。地表の面は $`u=0`$（排水）とセル中心までの距離 $`0.5\Delta\zeta`$ の片側差分を使い、底面の面はフラックス0とします。
- **時間**: 後退Euler（陰的、1次精度）。安定性による刻みの制限はありません。
- **非線形**: 未知数を各セルの間隙比 $`e_i`$ とし、各時間ステップでNewton法を使います。ヤコビアンは面ごとの厳密な微分から作る三重対角行列で、Thomas法で解きます。残差が減らないときはステップ幅を半分にします。
- **二次元**: 鉛直と水平のNewton掃引を交互に行い、掃引による更新量が許容値以下になるまで外側で反復します。水平掃引では、もう一方の方向の寄与を前の反復の値で固定します（lagged）。
- **収束しないとき**: 時間刻みを半分に分割して再試行します（`max_splits` 回まで）。それでも収束しなければ `RuntimeError` で報告します。間隙比と水圧は任意の上限でクリップしません。非有限の値は `FloatingPointError` で報告します。
- **許容値**: 1ステップの変化量に比例させ、丸め誤差より十分大きい床 $`1.0\times10^{-13}\max(1,|e|)`$ を置きます。

### 面のフラックスの作り方（実装上の判断）

支配方程式 (3) を、$`e`$ の勾配の形でそのまま差分化すると、地表の片側差分と自重項の釣り合いが $`O(\Delta\zeta)`$ ずれます。
すると無載荷でも見かけの圧密が生じます（記録: `nz=4` で1.55 mm）。

本実装は (1) の圧力形を使い、$`\partial u/\partial\zeta`$ を離散的な水圧の差から直接作ります。
全応力と有効応力は同じ離散化なので、自重と釣り合った状態（$`u=0`$）では面のフラックスが厳密に0になります。
無載荷の沈下は厳密に0、定常状態の $`\max|u|`$ はほぼ0になります。

## 9. 二次元化（著者による拡張）

平面ひずみ $`\varepsilon_x=0`$ を仮定し、水平方向の流れを加えます。水平方向は物質座標ではなく物理座標 $`\xi`$ を使います。

$$
\frac{\partial}{\partial \xi}\left[\frac{k}{\gamma_w}\frac{\partial u}{\partial \xi}\right],
\qquad
\frac{\partial u}{\partial \xi}=\frac{\partial \sigma_v}{\partial \xi}+\frac{1}{a_v}\frac{\partial e}{\partial \xi}.
$$

ここで $`\sigma_v`$ は全鉛直応力（$`\sigma_{\mathrm{top}}+\sigma_{\mathrm{load}}+`$ 自重）です。

荷重 $`\sigma_{\mathrm{load}}`$ は、中央の等分布帯荷重に対する弾性半無限体の鉛直応力増分です（線形モデルと同じ式）。

$$
\theta=\mathrm{atan2}(X+a,z),\quad
\beta=\mathrm{atan2}(X-a,z),\quad
\alpha=\theta-\beta,
$$
$$
\sigma_{\mathrm{load}}(X,z)=\frac{q}{\pi}\left[\alpha+\sin\alpha\cos(\theta+\beta)\right].
$$

$`X`$ は中央からの水平距離、$`a`$ は帯荷重の半幅、$`q`$ は載荷強度です。

この二次元化は著者による拡張で、三笠が公表した理論ではありません。次を解きません。

- せん断変形と水平力の釣合い。
- 載荷にともなう全応力の再配分（$`\sigma_{\mathrm{load}}`$ を初期値に固定する）。
- 変形と水圧の連成（Biotの三次元圧密。[references.md](references.md) を参照）。
- 空間的に変化する沈下場の完全な弾性適合条件。

水平方向の面では $`\partial\sigma'/\partial\xi`$ を面の有効応力で近似するため、鉛直方向より境界近傍の次数が一段低くなります。
また、水平の式は物理座標なので、鉛直の $`1/(1+e)`$ の因子を含みません。
帯荷重を広く取ったときの2次元解と1次元解の相対差は `1.7e-5` です（[README の検証](../README.md#検証)を参照）。

## 10. 線形小ひずみモデルとの関係

`consolidation.py` は、一定係数の2次元水圧拡散 $`\partial u/\partial t=c_v\nabla^2u`$ を解き、各鉛直柱の拘束圧密で沈下へ換算します（寺田型）。
有限ひずみモデルの小ひずみ極限（ひずみと $`e`$ の変化が小さく、$`k`$ と $`a_v`$ の変化が無視できる）では、両者は一致します。

本実装は、この極限で寺田の解析解と一致することを確認しています（$`T=0.1,0.2,0.4`$ で差 $`-0.10`$〜$`-0.08`$ ポイント）。
比較に使う同じ $`c_v`$ と弾性係数は、`mikasa_consolidation.comparison` の `matched_cv()` と `matched_modulus()` が返します。

## 11. 限界

- 原著本文は未確認で、逐語的な一致は主張しません。
- 二次元化は著者による拡張です。
- 二次圧密、時間変動荷重、不均一な透水性、載荷にともなう全応力の再配分、せん断、三次元化は扱いません。
- 実地盤への適合性と設計精度は未検証です。
