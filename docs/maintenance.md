### (a) 数式・境界・検証

- 確認したこと: 拡散方程式と CN の符号、`(I-½cΔtL)u^{n+1}=(I+½cΔtL)u^n` の向き、地表 Dirichlet と
  底面・側面 Neumann の鏡映差分、半幅セルの重みで対称化した固有値分解、零固有値の固定、
  `log1p` による増幅率、`nt` が奇数のときの符号反転。
- 根拠: 直接 CN 解との全境界一致（`test_eigenmode_evaluation_matches_direct_crank_nicolson_including_boundaries`）、
  空間・時間の2次収束、帯荷重と線荷重積分の一致。
- 指摘1: 刻み制限 `Δt ≤ 1/(cv(1/Δx²+1/Δz²))` は、最悪モードの `h=½Δtλ` を -2 まで許す。
  `h<-1` では増幅率が負になり、符号反転するモードが残る。README の「数値振動が生じない」は
  標準的な十分条件（`h≥-1`）より強い主張で、実装では保証していない。
  出力に負値を確認した例は見つけていない。コード変更は本 PR の範囲外とし、Issue #8 に分離した。
  → #8 で刻みの上限を `0.5/(cv(1/Δx²+1/Δz²))` に締め、README の条件を `≤ 1/2` に直した。
- 指摘2: `dx == 0` の検査は、`length` が極端に小さく格子が細かい場合のアンダーフロー以外では到達しない。
  境界の検査として残した。
- 対応: 上記以外の修正なし。当時の13テストが両環境で成功（現在は17テスト）。

### #24（修正済み）: 三笠の有限ひずみ圧密理論の実装

旧版は一定係数の線形拡散（`consolidation.py`）を三笠理論として提示していた。これは実装したい内容と
違うため、Issue #24 として起票し、物質座標の有限ひずみ圧密を実装した。

| ファイル | 役割 |
| --- | --- |
| `finite_strain.py` | 有限ひずみ圧密（主実装）。`FiniteStrainConsolidation`。 |
| `consolidation.py` | 一定係数の線形小ひずみ圧密（参照・比較用）。 |
| `Mikasa.py` | 有限ひずみの入口。`MikasaConsolidationSimulator` はその別名。 |
| `Terzaghi.py` | 線形の入口と、両理論の比較（`matched_cv`、`matched_modulus`、`run_pair`、`plot_comparison`）。 |

扱う要素:

- 物質座標 $\zeta=\int dz/(1+e)$、圧縮則 $e=e_0-C_c\log_{10}(\sigma'/\sigma'_{\mathrm{ref}})$、透水則 $k=k_0 10^{-(e_0-e)/C_k}$。
- 自重 $\gamma_w(G_s+e)$ を含む全応力と、排水にともなう有効応力への再配分。初期状態は地表応力と自重に釣り合うプロファイルを数値的に求める。
- 移動表面（沈下）と、固体体積一定の座標。
- 数値解法はセル中心の有限体積と後退Euler（陰的）。鉛直は Newton 法で、面ごとの厳密な微分から作る三重対角ヤコビアンを Thomas 法で解く。
- 二次元は $\varepsilon_x=0$ を仮定し、鉛直と水平の Newton 掃引を交互に行い、更新量が許容値以下になるまで外側で反復する。
- 収束しないときは時間刻みを自動で分割し（`max_splits` まで）、それでも収束しなければ `RuntimeError` で報告する。間隙比・水圧はクリップしない。

実装上の判断:

- 面のフラックスは $F=k/(\gamma_w(1+e))\,\partial u/\partial\zeta$ の形で、$u$ の離散差から直接作る。
  等価な $D\,\partial e/\partial\zeta+q_{sw}$ 形（当初実装）は、地表で片側差分と自重項の釣り合いが
  $O(\Delta\zeta)$ ずれ、無載荷でも見かけの圧密（`nz=4` で1.55 mm）を生じた。圧力形に変えた結果、
  無載荷の沈下は厳密に0、定常状態の `max|u|` はほぼ0、粗い格子での定常解の `e` 誤差は約20分の1になった。
- 反復の許容値は1ステップの変化量に比例させ、`1e-13·max(1,|e|)` の床を置く。床が小さすぎると
  丸め誤差の水準に達せず、達成不能な閾値で時間分割が連鎖する（`1e-15` で457回の分割を観測）。
- 二次元化は著者による拡張であり、三笠が公表した理論ではない。原著本文は確認しておらず、逐語的な一致は主張しない。
- 入力検証、`reset`、`get_current_state`、`plot_results` の契約は線形モデルと揃えた。`nx=1` は線図、`nx>=2` は物理深さによる塗り分け図にした（`nx=1` では物理深さが2次元になるため `contourf` の次元が合わない）。
- 無載荷テストは線形モデルの「厳密に0」と有限ひずみモデルの契約を分けた。有限ひずみモデルは自重と釣り合う初期プロファイルを数値的に作るため、
  無載荷でも厳密な0にはならない（実測 `max|u| ≤ 1.7e-13 kPa`、沈下は厳密に0）。判定を緩めたのではなく、
  有限ひずみ側には格子を変えた複数条件（`nz=4, 16, 64`）の検証を新たに追加した。
