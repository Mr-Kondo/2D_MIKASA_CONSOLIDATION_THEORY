# 実行環境とGPUの検証（2026-10-22）

## 結論と対象

有限ひずみモデルの既定例では、GPU併用はCPUより遅くなりました。
これはApple M5上の試作方式の測定であり、GPU一般やCUDAの性能を示すものではありません。
公開APIは引き続きNumPyのCPU計算です。実験用のMLXは通常の依存関係に追加していません。

## GPU計算の比較

### 方法

- Apple M5（10コアGPU、32 GBメモリ）、Python 3.13.5、NumPy 2.5.4、MLX 0.32.4。
- CPUは現在の実装。GPU併用は三重対角方程式だけをMetalの1カーネルで解きます。
  1スレッドが1列を担当し、Thomas法の前進消去と後退代入を行います。
- 非線形残差、ヤコビアン、Newton反復、許容値、時間刻みの自動分割は現在のCPU倍精度実装を使います。
  Metal側は単精度で解き、結果をCPU倍精度に戻します。許容誤差は緩めません。
- MLXのGPU上で`float64`の演算を試すと、`float64 is not supported on the GPU`となりました。
  そのため、現在の倍精度計算全体を単純に置き換える方法は採用していません。
- 各条件で初回を別記し、その後にCPUとGPU併用を交互に各3回実行します。
  初期化、型変換、転送、GPU完了待ち、出力配列の計算を含む時間の中央値を比較します。描画とPython起動は含みません。
  保存したログは21〜101と201〜401を別プロセスで測定したものです。再現スクリプトは全条件を順番に実行します。
- 両方式で同じ格子・時間・材料条件を使います。21×21は既定の3650日、730ステップです。
  51×51・101×101は1日（20ステップ、`dt=0.05`日）、201×201・401×401は0.02日（20ステップ、`dt=0.001`日）です。
  格子間では計算期間が異なるため、行をまたぐ速度比較はしません。
- 各条件の初回について、間隙比・過剰間隙水圧・沈下を`atol=rtol=1e-8`で比較し、自動分割数も照合します。
  単独のソルバーは1セル・1列・複数列でNumPyのThomas法との一致と、密行列で独立に組み立てた方程式の残差を確認します。

### 結果

| 格子 | ステップ数 / 刻み[日] | CPU中央値[秒] | GPU併用中央値[秒] | CPU時間 / GPU時間 |
| --- | --- | --- | --- | --- |
| 21×21 | 730 / 5.0 | 2.6223 | 5.6394 | 0.465 |
| 51×51 | 20 / 0.05 | 0.1672 | 0.2207 | 0.758 |
| 101×101 | 20 / 0.05 | 1.6441 | 1.6738 | 0.982 |
| 201×201 | 20 / 0.001 | 1.2719 | 1.2954 | 0.982 |
| 401×401 | 20 / 0.001 | 17.1949 | 17.1056 | 1.005 |

1より大きければGPU併用が速い値です。401×401の差は約0.5%で、反復間の変動幅より小さく、明確な高速化とは判断しません。
既定例はGPU併用が約2.15倍遅くなりました。

比較した全条件で、自動分割は両方式とも0でした。最大絶対差は、間隙比`4.45e-16`、水圧`4.0e-13 kPa`、沈下`2.6e-16 m`以下です。
これらは今回の条件での結果であり、単精度ソルバーが常にこの精度を満たす保証ではありません。

初回と全反復の時間、実行環境、誤差は[測定ログ](evidence/gpu-apple-m5-20261022.jsonl)に保存しています。
速度差の原因ごとの時間は測定していないため、転送だけが原因とは断定しません。

### 再現

リポジトリのルートで実行します。Apple MetalのGPUが必要です。

```bash
MPLBACKEND=Agg uv run --locked --with mlx==0.32.4 python benchmarks/gpu.py
```

このスクリプトのGPU経路は実験専用です。正式な`device`選択として公開していません。
任意の材料条件での堅牢性、長期間の大規模計算、GPU上への計算全体の常駐、CUDAは未検証です。

### 採用しなかった試行

最初に、現在の`_tridiagonal_batch`の配列演算をMLXで実行・コンパイルする試作も走らせました。
既定例で長時間かかり、行ごとの`SliceUpdate`などをGPUへ発行していたため、完走前に打ち切りました。
この試行から完走時間や高速化率は算出していません。最終実験ではThomas法を1カーネルにまとめています。
また51×51で`dt=5`日の試行は長時間かかったため打ち切りました。
大きい格子の最終比較は上記の短期条件に限り、既定の3650日を大きい格子で完走したとは扱いません。

## 実地盤データと残作業

実測の沈下・過剰間隙水圧の時系列との比較は未実施です。
解析解との一致やOS間のテスト成功だけでは、実地盤への適合性は示せません。
この点を「問題なし」として閉じる根拠はありません。

実地盤検証には、利用条件が明確な公開データと、層厚・排水境界・載荷履歴・初期間隙比・圧縮則・透水則の条件が必要です。
完了条件は、パラメーターの出典、比較時点と誤差指標、格子・時間刻み依存性、モデルで表現できない条件を記録することです。
文献の図を数値化する場合は、抽出方法と読取誤差も区別します。
独立した追跡課題として扱い、データが不足したまま実装の妥当性を断定しません。
